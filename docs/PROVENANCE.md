# Source provenance

Screen Scout Windows derives from the owner's [Screen Scout macOS repository](https://github.com/anaumovs/screen-scout), using commit [`04707eacdddcc03cbccdd74e205557088dd13049`](https://github.com/anaumovs/screen-scout/commit/04707eacdddcc03cbccdd74e205557088dd13049) as the Windows port's starting point.

The application uses native Windows Forms and Windows input APIs. Its test version adds purple secondary clicking areas and the November 16, 2026 reliability corrections. The original Mac repository is not changed by this publication.

The public release retains the application name **Screen Scout Test**, its separate settings and shortcut behavior. Publishing the Windows repository does not replace an existing main installation.

Bundled .NET runtime license and third-party notices are included under `notices` in the Windows download.
